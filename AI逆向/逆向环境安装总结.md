## 一、整体干了什么

为 Claude Code 安装了一套 **JS 接口逆向工程工具链**，包含两个部分：

1. **一个 skill（技能/指令包）**：`hello_js_reverse_skill` —— 提供逆向分析的方法论、流程、经验库
2. **一个 MCP server（工具集）**：`camoufox-reverse` —— 提供反检测浏览器 + 35 个逆向操作工具

两者配合使用：skill 告诉 Claude「该怎么分析」，MCP 提供「具体能用的工具」。

## 四、有什么用

### 整体能力

针对**自有平台或已授权平台**的 Web API，做签名分析与接口对接：
- 还原前端加密 / 签名逻辑（如 `sign`、`a_bogus`、`X-Bogus`、`msToken`、瑞数 cookie 等）
- 用 Node.js / Python 复现算法，产出**纯协议脚本**（不依赖浏览器即可跑）

### MCP 提供的 35 个工具（分类）

| 类别 | 主要工具 | 用途 |
|------|---------|------|
| 浏览器 | `launch_browser` / `navigate` / `click` / `take_screenshot` | 反检测浏览器操作 |
| JS 执行 | `evaluate_js` | 页面内执行任意 JS |
| 脚本 | `scripts` / `search_code` | 读取/搜索页面 JS 源码 |
| Hook | `hook_function` / `inject_hook_preset` / `remove_hooks` | 拦截函数调用、捕获 I/O |
| 网络 | `network_capture` / `list_network_requests` / `get_request_initiator` | 抓包 + 定位签名函数调用栈 |
| JSVMP | `hook_jsvmp_interpreter` / `instrumentation` / `compare_env` | 虚拟机保护的字节码插桩、环境对比 |
| Cookie | `cookies` / `export_state` / `analyze_cookie_sources` | Cookie 读写 + 归因分析 |
| 验证 | `verify_signer_offline` | 用真实样本离线验证签名代码 |
| 自检 | `check_environment` | 环境检查（skill 启动 Checklist 第 1 项） |

### skill 的核心方法论

- **硬约束 Checklist**：每次分析前必须复述 3 项（环境自检 / 经验库速查 / 方案意图声明）
- **四条红线**：① 不跳过 Checklist ② 不重复分析已有案例 ③ 最终方案不用浏览器过反爬 ④ 不硬编码业务 cookie
- **反爬三分法**：签名型（瑞数/Akamai）/ 行为型（TikTok/抖音）/ 纯混淆
- **JSVMP 双路径**：路径 A 算法追踪（四板斧）/ 路径 B 环境伪装（jsdom 六步法）

## 五、怎么用

> ⚠️ skill 和 MCP 都在**会话启动时加载**，安装后必须新开 Claude Code 会话才生效。

在新会话中：

```
/hello_js_reverse_skill <目标URL> <加密参数名>
```

示例：
```
/hello_js_reverse_skill https://example.com/api/list sign
```

或用自然语言：「分析 https://xxx.com 的 a_bogus 参数签名」
